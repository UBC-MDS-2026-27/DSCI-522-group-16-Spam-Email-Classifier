## How To Run The Analysis 
1. Install the following (if not already installed):
    - [uv](https://docs.astral.sh/uv/getting-started/installation/)
    - [Quarto](https://quarto.org/docs/get-started/)
    - [Git](https://git-scm.com/downloads)

2. Clone this repository and go to it:

    ```
    git clone https://github.com/UBC-MDS-2026-27/DSCI-522-group-16-Spam-Email-Classifier.git
    cd DSCI-522-group-16-Spam-Email-Classifier
    ```

3. Install Python 3.14 and all packages required (i.e. the computational environment):

    ```
    uv sync
    ```

4. Render the report:

    ```
    uv run quarto render analysis/spam-email-classifier-report.qmd
    ```

5. Open the analysis/spam-email-classifier-report.html via browser
